# Banka Yönetim Sistemi (Bank Management System)

Java, Spring Boot ve PostgreSQL kullanılarak geliştirilen bir banka yönetim uygulamasıdır. Bu proje, backend geliştirme becerilerimi geliştirmek ve yazılım portföyü oluşturmak amacıyla hazırlanmaktadır.

## Projenin Amaçları

- Müşteri kayıtlarını oluşturmak ve yönetmek
- Banka hesapları açmak ve hesapları yönetmek
- Hesaplara para yatırmak ve hesaplardan para çekmek
- Hesaplar arasında para transferi yapmak
- Hesap hareketlerini ve işlem geçmişini görüntülemek
- Backend geliştirme ve veritabanı tasarımı konularında pratik yapmak

## Kullanılan Teknolojiler

- Java 21
- Spring Boot
- PostgreSQL
- Spring Data JPA / Hibernate
- Maven
- Postman
- Git ve GitHub

## Proje Durumu

Gereksinim analizi ve planlama aşamasındadır.

## Not

Bu proje eğitim ve portföy oluşturma amacıyla geliştirilmektedir. Gerçek bankacılık işlemlerinde kullanılmak üzere tasarlanmamıştır.
